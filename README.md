# FossilNote

FossilNote is a quiet collection board for natural history museums. Track every specimen in a collection, mark specimens as cataloged, filter by specimen type or priority, and keep a collection selected while you move between views.

## Getting started

    npm install
    npm run dev

Useful checks:

    npm test
    npm run typecheck
    npm run build

Data is saved locally in the browser. No network or account is required.
